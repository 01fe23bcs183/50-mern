# Implementation Notes

This project includes a ready-to-run MERN stack implementation with authentication and CRUD flows.

## Getting Started
1. Install dependencies in `server/` and `client/`.
2. Copy `server/.env.example` to `server/.env` and update the values.
3. Create a `client/.env` with `VITE_API_URL=http://localhost:5000/api`.
4. Run `npm run dev` in `server/` and `npm run dev` in `client/`.

## Included Features
- JWT authentication with register/login.
- CRUD APIs for core entities.
- React pages for managing each entity.
